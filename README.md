# 이은진 연구 포트폴리오

추천시스템, 언어모델, 데이터 분석 및 음악·수어 AI 프로젝트를 정리한 대학원·연구실 지원용 포트폴리오입니다.

**[포트폴리오 사이트](https://molba2see.github.io/research-portfolio/)** · **[연구 포트폴리오 PDF](assets/research-portfolio.pdf)** · [GitHub 프로필](https://github.com/molba2see)

## 구성

- 12개 프로젝트의 문제 정의, 개인 기여, 결과와 한계
- 추천시스템·언어모델·데이터 분석·대회 분야 필터
- 관세청·해운물류·KOPIS·날씨 콘테스트 기록
- 모여락 통합 전처리와 합주 피드백 시제품의 실험 기록
- 학회 운영진, 드림멘토, 학력과 자격증
- 추천 베이스라인 지표 비교

## 문서 버전

- 연구 포트폴리오 PDF: 2026.10.10 갱신, 15쪽
- 연구 CV PDF 및 Word, 연구 포트폴리오 Word: 2026.10.09 작성본

## 로컬 미리보기

빌드 없는 HTML/CSS/JavaScript 사이트입니다. 저장소 루트에서 정적 서버를 실행합니다.

```bash
python -m http.server 8765
```

GitHub Pages는 `main` 브랜치의 루트를 배포합니다. 프로젝트 원고는 `app.js`, 화면은 `index.html`과 `style.css`, 다운로드 문서는 `assets/`에 있습니다.
